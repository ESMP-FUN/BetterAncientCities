# Welcome

Better Ancient Cities makes Minecraft's Ancient Cities reusable on a multiplayer server: every player gets their own chest loot, the loot comes back on a timer, and the city is protected from griefing. It finds every Ancient City in your world by itself, with no setup per city.

***

## Features

* **Automatic discovery.** Cities are found as players explore near them, using Minecraft's own structure data. No WorldEdit, no commands per city.
* **Per-player chests.** Every player gets their own copy of each city chest, so the second player to arrive still finds full chests.
* **Loot refresh.** Each city refills on its own timer, starting when someone first loots it, so cities never all refresh at once.
* **Protection.** The city's buildings can't be broken, built on, flooded, burned, pushed by pistons or blown up. The rock between the buildings can still be mined.
* **Snapshots.** Save a city's blocks and put them back later, undoing griefing and sculk spread.
* **Player data.** Chests looted, time spent, deaths and blocked griefing, per player and per city. See exactly what a player took from each chest.
* **Loot bans.** Stop one player looting one city. They can still walk through it.
* **Staff menu.** `/ancient menu` covers everything.

***

## Requirements

* **Minecraft 1.21.1+.** Use the `-mc26` build for Minecraft 26.0 to 26.2, or the `-mc263` build for 26.3.
* **Paper, Folia, or Purpur.**
* **Java 21+** (Minecraft 26.x servers run on Java 25).

Better Ancient Cities works on its own. It does not need any other plugin.
